Як узгодити й додати проєкт

  1. Repo — окремий GitHub-репозиторій (публічний або з доступом команді).
  2. README — мета, хто owner, як запустити, посилання на live/docs.
  3. tools.json — один об’єкт у цьому репо (id, title, status, links).
  4. Зворотне посилання — у README проєкту додати «Part of DevOps Hub».
  5. Опційно — Confluence-сторінка з embed цього порталу.
